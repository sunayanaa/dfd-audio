# dfd-audio

**Differential Filterbank Divergence: Isolating Front-End Warping Effects Across Music Corpora**

Code repository for the paper submitted to *IEEE Signal Processing Letters*.
### Sridharan Sankaran

## Overview

This repository implements the Differential Filterbank Divergence (DFD) estimator, a model-free metric that quantifies how much a target filterbank amplifies or compresses spectral divergence between two music corpora relative to a matched linear reference. DFD isolates the front-end's geometric contribution from intrinsic corpus differences, enabling pre-deployment filterbank auditing without classifier training.

**Core formula:**

$$\overline{\mathrm{DFD}}(\mathcal{A}, \mathcal{B}; \varphi) = \overline{D}_{\mathrm{KL}}(\varphi) - \overline{D}_{\mathrm{KL}}(\varphi_0^{(n)})$$

where $\varphi_0^{(n)}$ is a matched linear reference with the same number of bands as $\varphi$.

Positive DFD: filterbank amplifies cross-corpus divergence beyond a neutral baseline.
Negative DFD: filterbank compresses divergence.

## Programs

### `01_synthetic_validation.py` — Experiment 1: Synthetic Signal Validation
**GPU required: No | Runtime: ~4 minutes**

Validates the DFD estimator on three controlled synthetic signal pairs before any corpus experiment.

| Pair | Signal A | Signal B | Purpose |
|---|---|---|---|
| P1 | 12-EDO harmonic series (f₀=220 Hz, K=20) | 53-EDO harmonic series | Microtonal discrimination across filterbanks |
| P2 | Pink noise (seed A) | Pink noise (seed B) | Same-distribution null control (DFD-bar ≈ 0) |
| P3 | Harmonic series | Randomly detuned harmonics (ε sweep) | Resolution sensitivity vs detuning magnitude |

Key design: each filterbank is compared against a matched linear reference with the **same number of bands**, isolating frequency warping from dimensionality differences.

**Outputs (Google Drive):** `exp1_synthetic_results.json`, `fig_01_01_p1_discrimination.png`, `fig_01_02_p3_epsilon_sweep.png`, `fig_01_03_p2_null_control.png`

### `01b_exp1_bootstrap_ci.py` — Experiment 1b: Bootstrap Confidence Intervals

**GPU required: No | Runtime: < 1 minute**

Computes bootstrap 95% confidence intervals (CIs) on DFD-bar for Experiment 1 (P3 epsilon sweep) by resampling filters with replacement ($B=500$). Because raw per-clip energy matrices were not saved by the initial synthetic validation program, filter-resampling is utilized as a proxy for clip-level uncertainty. Point estimates for P1 $T_m$ values are reported as exact estimates from the saved JSON. Note that several P3 CIs cross zero (e.g., Mel at $\epsilon=0.01$, CQT at $\epsilon \ge 0.05$), reflecting high filter-to-filter variance at large detuning; only cells whose CI excludes zero should be cited as significant. This script is designed to run immediately after `01_synthetic_validation.py`.

* **Inputs (Google Drive):** The script requires `exp1_synthetic_results.json` to access DFD vectors and $T_m$ values from Experiment 1.
* **Secondary Inputs:** The script also copies `exp2_energy_matrices.npz`. This matrix is generated as an output of the cross-corpus experiment. It is retained for future clip-level CI extension but is not actively used in this cell.


* **Outputs (Google Drive):** The script generates `exp1_ci_results.json`.
* **Output Details:** This file contains 95% CIs for P3 DFD-bar per filterbank and epsilon. It also contains exact $T_m^{\max}$ and peak Hz for P1.

### `01c_p1_bootstrap_ci.py` — Experiment 1c: P1 Discrimination Bootstrap Confidence Intervals

**GPU required: No | Runtime: < 2 minutes**

Computes bootstrap 95% confidence intervals on the P1 per-filter discrimination statistic $T_m^{\max}$ and peak frequency filter indices across all four filterbanks. For each of $B = 500$ replicates, $N$ clips are resampled with replacement from the saved 12-EDO and 53-EDO energy matrices. The statistic $T_m$ is re-evaluated across all filters, taking the maximum and computing the 2.5th and 97.5th percentiles. These intervals provide the clip-level uncertainty metrics reported in Table I.

* **Execution Order:** Run immediately after `01b_exp1_bootstrap_ci.py`.
* **Inputs (Google Drive):** `exp1_p1_energy.npz` (per-clip energy matrices for 12-EDO and 53-EDO conditions across all four filterbanks and matched linear references, generated by the updated Program 01).
* **Outputs (Google Drive):** `exp1_p1_ci_results.json` (bootstrap 95% CIs on $T_m^{\max}$ and peak frequency filter index per filterbank).

### `03_predictive_validity.py` — Experiment 3: Predictive Validity
**GPU required: No | Runtime: ~45 seconds**

Tests whether DFD-bar predicts cross-corpus classifier overconfidence without model training. Trains a logistic regression classifier (linear probe) on GTZAN mean log-energy features per filterbank. Evaluates on each non-Western corpus using the overconfidence gap $\bar{c}^{\mathcal{T}} - \bar{c}^{\mathcal{W}}$ as the dependent variable. Computes Spearman ρ across 20 (filterbank, corpus) pairs.

Reuses energy matrices from Experiment 2 (no audio reprocessing). Logistic regression is chosen as a minimal-capacity probe so that performance differences reflect front-end geometry, not model capacity. Non-Western corpora carry no GTZAN genre labels; confidence gap is used as a label-free proxy.

**Inputs (Google Drive):** `exp2_energy_matrices.npz`, `exp2_dfd_results.json`

**Outputs (Google Drive):** `exp3_classifier_results.json`, `fig_03_01_dfd_vs_gap_scatter.png`

## Key Results

**Experiment 1:** DFD null control (P2) confirms near-zero values for identically distributed signals across all filterbanks (max |DFD-bar| = 0.007 nats). Mel is threshold-sensitive to 53-EDO microtonal deviations at filter boundaries ($T_m > 100$ near 1500–2000 Hz); CQT tracks continuously. Bark accumulates detuning divergence monotonically; CQT saturates at ε ≈ 0.05.

**Experiment 2:** Psychoacoustic filterbanks (Mel, Bark, ERB) compress cross-corpus divergence for Carnatic and Hindustani (z = −5.9 to −8.9). CQT amplifies divergence for Jingju (z = 14.1; 95% CI [+0.50, +0.78]) and Arab-Andalusian (z = 4.7; 95% CI [+0.11, +0.31]). Turkish Makam shows no significant DFD under any filterbank.

**Experiment 3:** Spearman ρ = +0.817 (p < 0.001, 95% CI [+0.58, +0.93], N = 20) between DFD-bar and classifier overconfidence gap, establishing DFD as a model-free pre-training predictor of cross-corpus classifier behaviour.

## Filterbanks

| Filterbank | Bands | Reference | Implementation |
|---|---|---|---|
| Mel | 128 | 128-band linear | `librosa.filters.mel` |
| Bark | 24 | 24-band linear | Zwicker (1961) formula |
| ERB | 64 | 64-band linear | Moore & Glasberg (1990) |
| CQT | 84 | 84-band linear | `librosa.cqt`, C1 fmin, 12 bins/oct |

Each filterbank is compared against a matched linear reference with the same number of bands, ensuring DFD measures warping geometry only.
